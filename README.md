# AI Technical Interviewer

Autonomous multi-turn AI technical interviewer for the 31-day AI Cohort.

Built with Next.js App Router, TypeScript, Breeth Graph Memory, and Gemini.

## Quick start

```bash
cp .env.example .env.local
npm install
npm run dev
```

Put API keys only in `.env.local`. That file is gitignored and must never be committed.

See open issues for the build roadmap.
